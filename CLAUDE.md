# Sanayi UI — Frontend (Next.js + TypeScript)

Ankara sanayi dükkanı puanlama platformunun frontend'i. Backend: `../sanayi` (Spring Boot, :8080).

## Hızlı Başlangıç

```bash
nvm use          # .nvmrc → Node 24 LTS (tek kaynak; CI de bunu okur)
npm ci
npm run dev     # http://localhost:3000 (Turbopack)
npm run build   # prod build
npm run lint
```

Env: `NEXT_PUBLIC_API_URL` (default `http://localhost:8080/api`), `NEXT_PUBLIC_RECAPTCHA_SITE_KEY` (anonim oylar için).

Ölçüm: `scripts/measure.sh <etiket> <providerId>` (prod build + `npm run start` açıkken; Lighthouse mobil, 3 koşu medyan). Baz/sonra değerler `specs/001-ui-modernization/baseline.md`.

## Konvansiyonlar

- Veri çekme Server Component'ta; etkileşim (form, harita) client component (`"use client"`).
- Sayfa numarası UI'da 1-based, backend'e 0-based gönderilir.
- Sort paramı Spring formatı: `sort=field,dir` (çoklu eklenebilir).
- Puan aralığı -5..+5; yorum max 500 karakter. Anonim kimlik `localStorage.sanayiAnonId`.
- Harita bileşenleri sadece client'ta yüklenir (leaflet SSR'da patlar) — `dynamic(..., { ssr: false })`, yalnızca client sarmalayıcıda (Server Component'te `ssr:false` yasak).
- **404 kalıbı**: `notFound()` bir `loading.tsx` Suspense sınırının İÇİNDE çağrılırsa akış 200 ile başlamış olur → durum kodu 404 olmaz. Bu yüzden detay doğrulaması `providers/[id]/layout.tsx`'te ve liste dosyaları `providers/(list)/` grubunda (liste loading'i [id]'yi sarmasın). Yeni dinamik rota eklerken aynı kuralı uygula. 003: `/providers/[id]/claim` aynı `[id]/layout` altında (sentetik/yok → 404); `/account/providers/[id]/edit` ve `/admin/providers/[id]` segmentlerinde `loading.tsx` YOK → sayfada `parsePositiveId` + `notFound()` gerçek 404.
- **Kimlik gerektiren veri (003, anayasa I'in dar sapması)**: JWT `localStorage`'da, sunucu göremez → hesap/admin verisi tarayıcıdan Bearer + `no-store` (`useAuthedData`); sayfa iskeleti, metadata (`robots: {index: false}`), kategori/marka listeleri (ISR) ve `searchParams` doğrulaması yine sunucu `page.tsx`'te. Her rota = sunucu `page.tsx` + `*Client.tsx`. Hesap sayfaları `AccountShell` içinde: hidrasyona kadar iskelet (`useSyncExternalStore`), belirteç yok/401 → "Giriş yapın" (`/login?next=<sayfa>`), `requireVerified` + doğrulanmamış → doğrulama boş durumu, hazırsa `children(me)` (render prop; `GET /api/user/me` — JWT `emailVerified` taşımaz).
- **`/login?next=`**: sunucu sayfa `safeNext` ile yalnız site içi göreli yolu kabul eder (`//`, `/\`, ters bölü, kontrol karakteri reddedilir; son emniyet `new URL(v, sahte-köken)` kökeni değişirse `undefined`) → LoginForm başarıda oraya döner. Oturumsuz "Dükkan öner" / "Bu dükkan benim" / AccountShell / AdminShell bağlantıları `next` taşır.
- **Server Action ile yeniden doğrulama**: liste/meta fetch'leri `next.tags` taşır (`providers`, `brands`, `categories`); düzenleme, geri alma, öneri onayı ve talep kararından sonra client `revalidateProviderViews(id, token)` çağırır → eylem çağıranın belirteciyle `GET /api/owner/providers/{id}` sorar (yalnız sahip/yönetici 200), sonra `revalidateTag(tag, "max")` (stale-while-revalidate; tek argümanlı biçim Next 16'da kalktı). Hatalar yutulur (ISR süresi zaten dolar).
- **Hata ekranları**: tüm `error.tsx`'ler `RouteError`'u yeniden dışa aktarır (sabit Türkçe metin, ham hata gösterilmez, `retry` sunucu verisini yeniden çeker); kök düzen hataları `global-error.tsx`; Türkçe 404 `not-found.tsx`.
- Tema: sunucu HTML'i `data-theme="dark"` (JS'siz de koyu), `themeInit` kayıtlı tercihi uygular; `<meta name="theme-color">` script'ten önce gelir ve ThemeToggle ile güncellenir (`viewport.themeColor` kullanılmaz).

## Notlar

- **URL-state kalıbı (Next 16 standardımız — useSearchParams KULLANMA)**: (1) URL'i SERVER sayfa okur (`await searchParams`), client bileşene başlangıç değerlerini PROP olarak indirir; (2) client, URL'e yazarken TIKLAMA ANINDA `new URLSearchParams(window.location.search)` ile mevcut query'yi kopyalar; (3) geri/ileri senkronu için server sayfa client bileşene URL'den türetilmiş `key` verir (key değişince remount = state reset). Örnekler: FilterBar, Pagination, MapSection (auto mod: `showMap` yoksa ekran genişliği), NearLocate, verify-email/reset-password (token prop olarak iner). `useSearchParams` yalnızca admin ekranı gibi tam-SPA sayfalarda ve MUTLAKA `<Suspense>` içinde kullanılır.
